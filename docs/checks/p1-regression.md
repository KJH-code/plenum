# P1 노트북 회귀 확인

P1(어댑터 층)은 동작을 바꾸지 않는 리팩터라서, 3단계 확인 항목이 0.3.1 과 같게 동작하는지 본다.
기준 = plenum 0.3.0 노트북 완료 기준.

Windows PowerShell 에서 한다. 블록마다 `cd` 로 시작하고 한 줄에 명령 하나다.

## 준비

```powershell
cd $HOME\Documents\GitHub\plenum
git fetch origin
git checkout claude/awesome-bell-zvjj96
git pull
```

```powershell
cd $HOME\Documents\GitHub\plenum\app
npm ci
npm test
npm start
```

- 막히면: `npm` 이 "스크립트를 실행할 수 없으므로"(실행 정책)로 막히면 `npm.cmd ci`·`npm.cmd test`·`npm.cmd start` 로 부른다.
- 브라우저로 `http://127.0.0.1:4317` 을 연다(사용 중이면 터미널에 찍힌 주소). 프로젝트 하나를 골라 새 세션(앱 안 채팅)을 연다.

## 확인할 항목

### ① 질문·승인 카드

할 것:
- 채팅에 보낸다: `AskUserQuestion 도구로 나에게 선택지 3개짜리 질문을 하나 해줘. 주제는 점심 메뉴.`
- 질문 카드에서 선택지 하나를 누른다.
- 채팅에 보낸다: `PowerShell(또는 Bash)로 git --version 을 실행해줘.`
- 승인 카드에서 "허용"을 누른다.

기대 결과:
- 질문 카드에 선택지 버튼(추천 강조, 기타 직접 입력)이 뜨고, 고른 답을 Claude 가 받아 이어서 답한다.
- 명령 승인 카드에 허용 / 이 세션 동안 허용 / 거부… 가 보이고, 허용하면 명령이 실행되고 결과로 답한다.

### ② 이 세션 동안 허용

할 것:
- 같은 채팅에서 승인이 필요한 명령 하나를 시킨다(예: `PowerShell 로 Get-ChildItem 을 실행해줘.`).
- 승인 카드에서 "이 세션 동안 허용"을 누른다.
- 같은 명령을 다시 시킨다.
- 다른 명령을 시킨다(예: `PowerShell 로 Get-Date 를 실행해줘.`).

기대 결과:
- 카드가 "허용 · 이 세션 동안 다시 묻지 않음"으로 바뀐다.
- 같은 명령은 다시 묻지 않고 실행된다.
- 다른 명령은 승인 카드가 다시 뜬다.

### ⑦ 고아 프로세스 정리

할 것:
- Claude 데스크톱 앱을 켜 둔다(이름이 같은 `claude.exe` 라 잘못 죽이지 않는지 본다).
- 채팅에 오래 걸리는 일을 시켜 응답 중으로 만든다(예: `1부터 300까지 한 줄에 하나씩 써줘.`).
- 응답 중에 `npm start` 를 돌린 서버 창을 강제로 닫는다(창의 X 버튼).
- 새 PowerShell 창에서 남은 프로세스를 본다:

```powershell
cd $HOME\Documents\GitHub\plenum\app
Get-CimInstance Win32_Process -Filter "Name='claude.exe' OR Name='node.exe'" | Select-Object ProcessId,CommandLine | Format-List
```

- 서버를 다시 켠다:

```powershell
cd $HOME\Documents\GitHub\plenum\app
npm start
```

- 다른 PowerShell 창에서 위 확인 명령을 한 번 더 돌린다.

기대 결과:
- 채팅 claude 는 명령줄에 `--input-format`·`stream-json` 이 있는 것으로 구분한다. 데스크톱 앱 claude 에는 이 인자가 없다.
- 서버 창을 닫은 직후 채팅 claude 가 남아 있으면, `npm start` 다시 켠 뒤에는 사라진다(`chat-pids.json` 으로 정리).
- 데스크톱 앱 claude 는 두 번 다 살아 있다.
